개인정보처리방침

1. 수집하는 정보 (최소 수집 원칙)

  • 계정: 앱이 자동으로 만드는 익명 계정 식별자 (가입에 이메일·전화번호·이름이 필요 없습니다)
  • 지역: 직접 고른 동 단위 지역과 그 동의 대표 좌표 (정확한 집 주소·실시간 GPS는 수집하지 않습니다. 번지까지 입력해도 동의 대표 좌표만 저장합니다)
  • 아이 정보: 애칭과 생년월(YYYY-MM)만 — 이름·성별·사진·생일(일 단위)은 수집하지 않습니다
  • 생활·이동 설정: 하루 활동·쉬는 시간, 외출 스타일, 이동 수단·이동 시간, 나가는 시각·집에 있어야 하는 시간, 관심 분야·놀이 스타일
  • 이용 기록: 플랜 생성·확정, 놀이 기록, 계정 ID와 연결된 앱 이용 기록(화면 이용·생성·확정, 날짜, 앱 버전)
  • 홈놀이 모드: 일반 또는 ‘아이가 아파요’ 선택 — 차분한 놀이를 고르는 데만 쓰며, 증상 등 건강 정보는 받지 않습니다
  • 의견(보내신 경우): 의견 본문, 회신 이메일(선택), 문제 재현용 자동 첨부 정보(앱 버전·기기 종류·요금제·지역·아이 월령)
  • 장소 제보(하신 경우): 장소 이름·주소·좌표, 방문 연월, 방문 확인 자료
  • 알림 설정과 푸시 토큰: 주간 알림을 켠 경우에만 — 알림 받을 요일·시각과 기기별 푸시 토큰(Expo가 발급하는 기기 식별 문자열). 토큰은 알림 발송 외에 쓰지 않고 로그·분석에 남기지 않으며, 계정 삭제 시 함께 파기합니다

만 14세 미만 아동에게서 직접 정보를 받지 않습니다. 부모(보호자)가 등록한 아이의 애칭과 생년월만 처리하는 최소수집 구조입니다.

2. 이용 목적

  • 아이 나이·지역·날씨에 맞는 주말·공휴일 플랜 추천
  • 홈놀이(발달 참고용) 추천 및 놀이 기록
  • 서비스 품질 개선을 위한 이용 통계 분석
  • 의견 확인·회신과 오류 재현, 장소 제보 확인
  • 주간 알림 발송 (알림을 켠 경우에만 — 주말 계획을 권하거나 준비된 추천을 알리는 용도)

3. 보관 및 파기

  • 수집한 정보는 서비스 이용 기간 동안 보관하며, 계정 삭제 또는 삭제 요청 시 지체 없이 파기합니다(남는 항목은 5번 참고).
  • 의견 본문·이용 기록·장소 제보 관측 기록은 수집일로부터 2년이 지나면 파기합니다.
  • 주간 추천 초안은 4주, 알림 발송 기록은 12주가 지나면 파기합니다.
  • 푸시 토큰은 기기에서 알림이 더 이상 수신되지 않는 것이 확인되면(재설치·권한 철회 등) 비활성화하고, 주간 알림을 끄면 발송 대상에서 제외합니다.
  • 법령에 별도 보관 의무가 있는 경우 해당 기간 동안만 분리 보관 후 파기합니다.

4. 제3자 제공 및 처리 위탁

이용자의 개인정보를 제3자에게 판매·제공하지 않습니다. 서비스 운영을 위해 아래 업체에 처리를 맡깁니다.

  • Supabase: 데이터베이스·로그인 (데이터 저장 위치: 대한민국)
  • Railway: API 서버 운영 — 앱과 주고받는 모든 정보가 이 서버를 거칩니다 (서버 위치: 미국)
  • OpenAI: 플랜 조합·안내 문구 생성 — 아이 월령, 하루 일정 시간표, 추천 유형(아픈 날 여부 포함), 이동 시간, 공개 장소 정보만 보냅니다. 계정 ID·아이 애칭·사용자 위치 좌표는 보내지 않습니다(장소 후보에는 장소 좌표와 장소까지의 거리가 들어갑니다)
  • Resend: 보내주신 의견을 운영자 메일로 전달 — 의견 본문, 계정 ID, 회신 이메일(입력한 경우), 자동 첨부 정보
  • Expo·Google Firebase Cloud Messaging: 주간 알림을 켠 경우에만 알림 문구와 푸시 토큰을 전달합니다
  • 기상청·에어코리아·카카오: 날씨·대기질·지역 검색 — 계정과 연결되지 않은 위치 좌표·검색어만 보냅니다

  • 거부 방법과 영향: 의견 보내기·주간 알림은 쓰지 않으면 해당 이전이 일어나지 않습니다. 플랜 생성에는 서버·조합 처리가 필요해 거부하시면 이용할 수 없으며, 계정을 삭제하실 수 있습니다

5. 이용자의 권리 · 계정 삭제

이용자는 언제든지 본인 및 등록한 아이 정보의 열람·수정·삭제, 계정 삭제를 요청할 수 있습니다.

계정 삭제는 앱에서 직접 하실 수 있습니다
내 정보›계정›계정 삭제
  • 삭제되는 항목: 계정, 아이 애칭·생년월, 지역·생활·이동 설정, 확정한 플랜, 놀이 기록, 장소 제보, 알림 설정·푸시 토큰
  • 계정 연결만 끊고 남는 항목: 의견 본문, 이용 기록, 장소 제보 관측 기록 — 누가 썼는지 알 수 있는 계정 연결과 회신 이메일은 지웁니다. 의견 본문에 직접 적으신 개인정보는 남으니 본문에는 개인정보를 적지 말아 주세요. 남는 기록은 수집일로부터 2년 뒤 파기합니다
  • 운영자 메일: 이미 운영자에게 메일로 전달된 의견은 요청하시면 지웁니다
  • 삭제는 즉시 반영되며 되돌릴 수 없습니다.

이메일 없이 자동 생성되는 익명 계정이라 웹에서는 본인 확인을 할 수 없어, 삭제 실행 경로는 앱 안에만 있습니다. 앱을 이미 지우셨다면 아래 문의 주소로 계정 ID(앱의 [내 정보] → [계정 ID])와 함께 요청해 주시면 대신 처리해 드립니다.
